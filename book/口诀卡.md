# 口诀卡：一页纸，把全书背下来

> 先背这四句：**先分性质，先留痕，人身优先，冲动不决。** 详见 [第 001 条](01-%E6%81%8B%E7%88%B1%E9%87%8C%E7%9A%84%E9%92%B1.md#e001)。

| 章 | 这一章想让你想明白的事 | 口诀 |
|---|---|---|
| 第一章 恋爱里的钱 | 恋爱里的钱，"心意"和"证据"要分开记账。钱的性质，不是你心里想的，是证据能证明的。 | 一看性质，二留字据，三防违法，四不冲动；小钱当心意，大钱要说明，借钱写借条，为婚留原话。 |
| 第二章 红线与保命 | 刑事风险不来自"坏"，来自"上头"和"说不清"。钱输了可以再要，刑事案子来了，几乎没有回头路。 | 不动手，不威胁，不传私密；醉酒不亲密，吵架先走开；被问话，先找律师。 |
| 第三章 同居与孩子 | 没领证，财产按出资算；有了孩子，义务按血缘算。同居是自由，不是婚姻。 | 同居不共有，出资看流水；生了就要养，验亲走正路。 |
| 第四章 彩礼纠纷 | 彩礼是"为结婚给的钱"，能不能退，看这笔钱的目的实现了没有。谈得明白，给得明白，才退得明白。 | 一看登记，二看同居，三看孩子，四看金额。 |
| 第五章 婚前准备 | 婚前花的是谈话的功夫，省的是婚后的官司。全书性价比最高的一章。 | 问清人，问清钱，问清未来，再谈协议；红灯三个以上，先别领证。 |
| 第六章 共同财产和婚内协议 | 婚后的钱，默认是"我们的"。想让它不是，要写下来，要分开放。 | 婚后所得共，婚前财产私；混了说不清，写了才算数。 |
| 第七章 读懂另一半 | 日子过不好，多半不是法律问题，是规则和沟通问题。法律面前，夫妻地位平等、义务对等；网上的极端口号，多数不是法律规则。 | 事实先于评价，大事先商量，吵架有边界。 |
| 第八章 离婚协议 | 离婚协议，是你这辈子签的最贵的一份合同。签字之前，每一项都要写到"执行时不用再猜"。 | 先盘家底，再谈条件，写到不用猜；冷静期里别提前过户。 |
| 第九章 离婚诉讼 | 官司打的是证据和程序，不是委屈。你有多委屈，法官不看；你拿得出什么，法官才看。 | 按时答辩，证据先行，只说事实；孩子看陪伴，财产看来源。 |
| 第十章 离婚之后 | 证书拿到手，只是一半；落到过户和执行，才算完。离婚后的日子，是另一场长期的事。 | 该过户的过户，该执行的执行，该清的账清；孩子的事，当成合作项目。 |
| 第十一章 已婚男性生存指南 | 最好的护身符，是选对人，做对事，照顾好自己。法条护得住财产，护不住日子。 | 选人看模式，做事留余地，在场比给钱重要，撑不住的时候找人说。 |

背不下来也没关系。遇到事，先翻[救急卡](救急卡.md)。

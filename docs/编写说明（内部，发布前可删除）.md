# 编写说明（内部，发布前可删除）

## 这本书是怎么来的

两份参考材料：

1. 一份目录图：8 章、68 篇，另有若干协议与起诉状模板；
2. 一份 AI 生成的稿子，约 2.4 万字，与目录图是两条不同的思路。

新书不沿用任何一份的目录，也不沿用句子。做法是：把两份材料涉及的知识点拆成清单，按新的逻辑重排成 12 章，每条重新起标题、重写正文，并补上它们没有的内容。

## 第四轮：改名，重排目录，改成"文章体"

用户的反馈有三层：

1. **书名不好。** 更喜欢参考稿那种有分量、一下子能记住的名字，但不要抄。新名字沿用它"狠词 + 指南 + 副标题"的结构，换了词：《不吃哑巴亏指南——男性婚恋护身之书》。"哑巴亏"呼应序言的主线：吃了亏，说不出口。
2. **目录和内容更喜欢参考稿。** 它的目录是顺着人生走的一条线：恋爱的钱 → 彩礼 → 婚前 → 婚后财产 → 读懂对方 → 离婚协议 → 离婚官司 → 已婚生存。新目录改成同样的主线，共 11 章：

| 章 | 对应参考稿的 | 我们多出来的 |
|---|---|---|
| 一、恋爱里的钱 | 恋爱纠纷 | 证据怎么存、思维盲区自测、婚恋诈骗 |
| 二、红线与保命 | 恋爱纠纷里的刑事风险 | 单独成章，补了男性遭遇家暴、被曝光 |
| 三、同居与孩子 | 同居、非婚生子女 | 亲子鉴定、同居买房 |
| 四、彩礼纠纷 | 彩礼纠纷 | 官方案例对照表、购车购房款 |
| 五、婚前准备 | 婚前准备 | 怎么开口提婚前协议、领证前十个红灯 |
| 六、共同财产和婚内协议 | 共同财产和婚内协议 | 加名、父母出资、夫妻债务、防火墙 |
| 七、读懂另一半 | 了解女人 | 把"口号"放回法律事实，不替任何一方站队；加了对方家人要钱 |
| 八、离婚协议 | 离婚协议 | 房贷、协议之后还有事、发现出轨的第一周 |

| 十一、已婚男性生存指南 | 已婚男性生存指南 | 照顾自己、找律师 |

3. **正文要打磨，分级和依据可以保留。** 所以保留页脚的"法律依据"和"把握度"，但正文从"字段表"改成"文章体"：

| 以前 | 现在 |
|---|---|
| 场景、道理、怎么做、成本、容易栽在哪、说句实在话，各占一栏 | 一句话导语，例子，规则和道理，做法，一句判断，写成一篇连续的小文章 |
| 并列的要点挤在一个长段里 | 并列的要点用列表，一目了然 |
| 136 篇字段表 | 123 篇文章，合并了过碎的条目（如证据的两篇合一） |

## 标题和语气

标题学的是"有人味"的手法：具体场景、点明代价、直接对"你"说话、动词开头。不学它的夸张和对立。

## 第三轮：向参考稿学表达和思路

用户反馈：参考稿整体做得很好，在表达和思路上比我们强。逐条对照后，差距在五处，对应的升级是：

| 参考稿强在哪 | 我们原来缺什么 | 怎么升级 |
|---|---|---|
| 有立场、有主线：开篇点出"男人就该多承担"怎么把人堵住 | 序言是场景加声明，缺"为什么好人也吃亏" | 重写序言：三个原因（没人教、开不了口、"男人就该多承担"）；坦白法律哪里对男女有明文不同、哪里完全对等 |
| 每篇是一篇小文章，有"为什么" | 条目是字段清单，缺道理 | 44 个重点条目加"道理"栏，讲法律为什么这样规定 |
| 有一套能背的框架（四大原则、六种钱、四大特征……） | 数字散在各条里，没成体系 | 新增全书总纲 [第 001 条](../book/01-%E6%81%8B%E7%88%B1%E9%87%8C%E7%9A%84%E9%92%B1.md#e001)；每章开头加"想明白的事"和口诀；自动汇总成《口诀卡》 |
| 有自我诊断：写"倒霉的人有什么共同盲区" | 只讲规则，没让读者看自己 | 新增 [第 004 条](../book/01-%E6%81%8B%E7%88%B1%E9%87%8C%E7%9A%84%E9%92%B1.md#e004)（四个盲区加八题自测）、[第 049 条](../book/05-%E5%A9%9A%E5%89%8D%E5%87%86%E5%A4%87.md#e049)（领证前十个红灯，双方适用） |
| 敢下判断，有人味 | 为稳妥把结论磨平了 | 每条末尾加"说句实在话"（全书 136 条）；明确标注这是判断不是法条，不分把握度 |

同时新增：[第 069 条](../book/06-%E5%85%B1%E5%90%8C%E8%B4%A2%E4%BA%A7%E5%92%8C%E5%A9%9A%E5%86%85%E5%8D%8F%E8%AE%AE.md#e069)、[第 075 条](../book/07-%E8%AF%BB%E6%87%82%E5%8F%A6%E4%B8%80%E5%8D%8A.md#e075)、[第 082 条](../book/08-%E7%A6%BB%E5%A9%9A%E5%8D%8F%E8%AE%AE.md#e082)，以及自动汇总的《话术手册》。

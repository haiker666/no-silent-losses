# 附录 I　离婚协议书

> 范本仅供参考，不能直接套用，每个家庭的情况都不一样。使用前请对照 [第 086 条](../book/08-%E7%A6%BB%E5%A9%9A%E5%8D%8F%E8%AE%AE.md#e086) 的十二项审查清单；签署前建议请律师审阅。协议里的每一项，都写到"执行时不用再猜"的程度。

**离婚协议书**

男方：＿＿＿＿＿＿，＿＿年＿＿月＿＿日出生，身份证号：＿＿＿＿＿＿＿＿＿＿
女方：＿＿＿＿＿＿，＿＿年＿＿月＿＿日出生，身份证号：＿＿＿＿＿＿＿＿＿＿

双方于＿＿年＿＿月＿＿日登记结婚，婚后生有＿＿子／女＿＿＿＿＿＿（＿＿年＿＿月＿＿日出生）。现因＿＿＿＿＿＿，夫妻感情破裂，双方自愿离婚，在平等、自愿、协商一致的基础上，就离婚事项达成如下协议：

**第一条　离婚意愿**
双方自愿离婚，双方均具有完全民事行为能力，均确认本协议是真实意思表示。

**第二条　子女抚养**

1. 子女＿＿＿＿＿＿由＿＿＿＿＿＿直接抚养；
2. 另一方每月＿＿日前，支付抚养费＿＿＿元，至子女年满十八周岁止。支付方式：转入＿＿＿＿＿＿账户。
3. 子女教育费、医疗费等大额支出，按＿＿＿＿＿＿比例分担。大额支出的范围：单笔超过＿＿＿元的。
4. 探望：
   - 每周＿＿＿，＿＿时至＿＿时；
   - 节假日：春节、国庆等的安排＿＿＿＿＿＿；
   - 寒暑假：＿＿＿＿＿＿；
   - 接送方式：＿＿＿＿＿＿，地点：＿＿＿＿＿＿；
5. 双方不得在子女面前贬低对方，不得干预对方与子女的正常联系；
6. 子女的户口、姓氏、保险、学籍：＿＿＿＿＿＿。

**第三条　房产**

1. 位于＿＿＿＿＿＿的房屋，产权证号＿＿＿＿＿＿，登记在＿＿＿＿＿＿名下，归＿＿＿＿＿＿所有；
2. 获得房产的一方，在＿＿年＿＿月＿＿日前，向另一方支付补偿款人民币＿＿＿元；
3. 该房屋尚未还清的贷款，余额＿＿＿元，由＿＿＿＿＿＿承担，银行同意变更借款人的，在＿＿日内办理变更；银行不同意的，由＿＿＿＿＿＿继续还款，并保证对方不因此承担责任；
4. 过户时间：自领取离婚证之日起＿＿日内办理完毕；过户产生的税费，由＿＿＿＿＿＿承担；
5. 一方不配合办理过户的，应当承担违约责任。

**第四条　车辆**
＿＿＿＿＿＿车辆，车牌号＿＿＿＿＿＿，归＿＿＿＿＿＿所有，过户在＿＿日内完成。

**第五条　存款、理财、股票、基金**
1. 双方名下的存款、理财等，归属如下：＿＿＿＿＿＿（逐项列出）；
2. 转账时间：自领取离婚证之日起＿＿日内。

**第六条　股权、公司**
＿＿＿＿＿＿公司的股权，归＿＿＿＿＿＿，对另一方补偿＿＿＿元，在＿＿年＿＿月＿＿日前付清。

**第七条　保险、公积金、养老金**
＿＿＿＿＿＿（按协议处理，或各自保留）。

**第八条　债务**
1. 双方确认，共同债务总额＿＿＿元，债权人＿＿＿＿＿＿，由＿＿＿＿＿＿承担；
2. 如一方承担了对方应负责的债务，另一方应当在＿＿日内偿还；
3. 双方确认，各自的个人债务，由本人承担；
4. 除本协议列明的以外，没有其他共同债务。如有，由发生债务的一方承担。

**第九条　其他财产**
家具、家电、贵重物品：归＿＿＿＿＿＿。

**第十条　经济补偿**
＿＿＿＿＿＿（如有家务补偿、经济帮助，写明金额与支付方式。没有的写"无"）。

**第十一条　违约责任**
一方不履行本协议的，应当向对方支付违约金＿＿＿元，并承担对方为主张权利支付的合理费用（包括律师费、诉讼费）。

**第十二条　财产披露与兜底**
1. 双方确认，已经向对方如实披露所有夫妻共同财产和债务；
2. 如发现一方隐藏、转移夫妻共同财产，另一方可以另行主张分割，该方应当少分或者不分；
3. 本协议签署后发现的、协议中没有处理的共同财产，双方另行协商分割。

**第十三条　生效**
本协议自双方签字之日起成立，自双方领取离婚证之日起生效。

**第十四条　其他**
本协议一式三份，双方各执一份，民政部门留存一份。

男方（签字、按手印）：＿＿＿＿＿＿　　女方（签字、按手印）：＿＿＿＿＿＿
日期：＿＿年＿＿月＿＿日

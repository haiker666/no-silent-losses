# 附录 H　婚内财产协议

> 范本仅供参考。婚内协议要在双方真实自愿的前提下签署，不要用逼迫的方式让对方签字。涉及大额财产，建议各自咨询律师并公证。

---

**婚内财产协议**

甲方：＿＿＿＿＿＿，身份证号：＿＿＿＿＿＿＿＿＿＿
乙方：＿＿＿＿＿＿，身份证号：＿＿＿＿＿＿＿＿＿＿

甲乙双方于＿＿年＿＿月＿＿日登记结婚。为理清婚姻存续期间的财产关系，增进互相信任，减少因财产产生的猜测和矛盾，双方自愿达成如下协议：

**第一条　目的**
本协议是为了明确财产归属，不是为了解除婚姻关系。

**第二条　财产清单**

| 财产 | 位置 / 账户 | 价值 | 取得时间 | 取得方式 | 本协议约定的归属 |
|---|---|---|---|---|---|
| | | | | | 甲个人 / 乙个人 / 共同 |

**第三条　婚后收入**
自本协议签订之日起：
1. 甲方的工资、奖金、劳务报酬，归＿＿＿＿＿＿所有；
2. 乙方的工资、奖金、劳务报酬，归＿＿＿＿＿＿所有；
3. 经营、投资收益，归＿＿＿＿＿＿所有；
4. 继承或受赠的财产，遗嘱或赠与合同明确只归一方的，归该方所有。

**第四条　共同账户与日常开支**
设立共同账户＿＿＿＿＿＿，每月存入＿＿＿元，用于家庭日常开支。

**第五条　重大支出**
单笔超过＿＿＿元的支出，应当提前商量。

**第六条　房产**
＿＿＿＿＿＿房屋，归＿＿＿＿＿＿所有，贷款由＿＿＿＿＿＿偿还。

**第七条　家务和照顾家庭的补偿**
一方因照顾孩子、老人，减少工作，对家庭做出较多贡献的，另一方同意＿＿＿＿＿＿（例如：每月划转＿＿＿元至对方账户，或在离婚时另行补偿＿＿＿元）。

**第八条　债务**
1. 双方各自以个人名义所负的债务，除用于家庭日常生活外，由负债方自行承担；
2. 对外借款、担保，应当事先告知对方。

**第九条　对外效力**
双方确认，本协议只在夫妻之间产生效力。对第三人，以第三人是否知道本协议为准。

**第十条　变更**
双方书面一致同意，可变更本协议。

**第十一条　争议解决**
协商；协商不成，向＿＿＿＿＿＿人民法院起诉。

**第十二条**
本协议一式两份，双方各执一份。修改处须双方签字。

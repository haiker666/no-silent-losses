# 后记

写完这本书，我最想说的，只有几句。

书里所有的内容，都是基于现行的法律条文和公开的典型案例。书里的例子和规则，只能作为参考，不能替代律师对你案子的一对一分析。法条是固定的，但每一段感情、每一起纠纷，细节千差万别。同样的行为，细微的事实差别，裁判的走向就会完全不同。

这本书的初衷，不是制造两性对立，不是教人算计伴侣。它希望男性可以在亲密关系里，同时拥有真诚和理性。

真诚，是对感情保有善意；理性，是看懂婚恋里潜藏的财产和人身风险。善意不需要裸奔，真诚可以搭配自我保护。

婚恋的本质，是两个人自愿合作经营一段生活。合作的前提，是双方权责对等，双向付出。当合作无法继续，你也清楚自己的权利和风险，知道如何体面、合法地保护自己。

不要等到付出巨大的代价之后，才去学习这些规则。最好的避险，是在风险到来之前，看懂规则，守住边界。

如果你正在经历其中的某一件事，先深呼吸，再翻回《救急卡》。如果你已经走过来了，希望这本书能帮你少走一点弯路，也帮你身边的人，少吃一点说不出口的亏。

最后，书里一定还有错。法条会变，口径各地不同，我也可能写错。发现了，请告诉我。
